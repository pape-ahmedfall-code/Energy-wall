# Checklist bibliographie (cours « Veille scientifique »)

- [ ] Format cohérent (APA, IEEE ou Chicago), sans mélange
- [ ] Au moins 15 références
- [ ] Au moins 5 papers peer-reviewed
- [ ] Au moins 3 rapports institutionnels
- [ ] Sources variées (pas uniquement OpenAI ou IEA)
- [ ] Dates récentes privilégiées (moins de 3 ans, sauf classiques)
- [ ] DOI ou URL stable pour chaque référence web
- [ ] Numéro de page pour chaque citation directe
- [ ] Ordre alphabétique ou d'apparition
- [ ] Générée via Zotero ou équivalent (export BibTeX dans `docs/veille/references.bib`), pas à la main

## Règles à ne jamais oublier

- Aucun LLM (ChatGPT, Claude, etc.) cité comme source.
- Aucun blog Medium ou post LinkedIn non sourcé.
- Pour chaque chiffre : d'où vient-il ? Quel est le biais de la source ? Quelle est notre position ?
